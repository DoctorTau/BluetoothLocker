# Происхождение
[English](UPSTREAM.md) · **Русский**

BLEUnlock: https://github.com/ts1/BLEUnlock, MIT, Takeshi Sone.
Проверенный tag 1.12.2: `c33a132f9b65ecd8fd55954a5e097a77b86c8a92`.
При первоначальном импорте исходная Git-история сохранялась merge-коммитом с документацией форка. Публичная ветка `master` начинается с корневого snapshot-коммита `a68877c` и не включает Git-историю upstream; просмотреть её там нельзя. Полная история upstream сохранена только локально в ветке `codex/watchlock-history`.
Upstream не собирался и не запускался. WatchLock сохраняет подход
NSStatusBar/CoreBluetooth, но удаляет разблокировку, пароль, клавиатурную
симуляцию, фоновые скрипты, медиаконтроль и сетевые обновления.
